# Решение проблемы подключения к Telegram

## Проблема: ConnectionError / TimeoutError

Программа не может подключиться к серверам Telegram.

## Причины:

1. **Telegram заблокирован в вашей стране/регионе**
2. **Проблемы с интернет-соединением**
3. **Firewall блокирует подключение**
4. **Проблемы с DNS**

## ✅ Решения:

### 1. Использовать VPN (РЕКОМЕНДУЕТСЯ)

Самый простой способ:
1. Установите любой VPN (ProtonVPN, Windscribe, 1.1.1.1)
2. Включите VPN
3. Запустите программу снова

### 2. Использовать прокси

Если у вас есть SOCKS5 или HTTP прокси:

1. Обновил программу - теперь она спросит про прокси
2. Запустите снова: `python telegram_sender_simple.py`
3. Когда спросит про прокси - ответьте "да"
4. Введите данные вашего прокси

#### Где взять бесплатный прокси:
- https://www.socks-proxy.net/
- https://free-proxy-list.net/
- https://hidemy.name/ru/proxy-list/

### 3. Использовать Telegram Desktop с MTProto прокси

Если ничего не помогает:

1. Откройте Telegram Desktop
2. Settings → Advanced → Connection type
3. Используйте MTProto прокси
4. После подключения в Telegram Desktop попробуйте запустить программу

### 4. Изменить DNS

Попробуйте изменить DNS на:
- Google: 8.8.8.8, 8.8.4.4
- Cloudflare: 1.1.1.1, 1.0.0.1

## 🔧 Проверка подключения:

Откройте командную строку и выполните:

```cmd
ping 149.154.167.50
```

Если пинг не проходит - проблема в сетевом подключении к Telegram.

## 🚀 Альтернатива - использовать Telegram Bot API

Если ничего не помогает, могу сделать версию через бота (но он будет отправлять от имени бота, а не от вашего имени).
