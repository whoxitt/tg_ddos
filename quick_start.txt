📋 ШАГ 1: УСТАНОВКА
───────────────────────────────────────────────────────
1. Дважды кликните на install.bat
2. Дождитесь окончания установки

📱 ШАГ 2: ПОЛУЧЕНИЕ API КЛЮЧЕЙ
───────────────────────────────────────────────────────
1. Откройте https://my.telegram.org
2. Войдите в аккаунт
3. Перейдите в "API development tools"
4. Создайте приложение
5. Скопируйте api_id и api_hash

🚀 ШАГ 3: ЗАПУСК
───────────────────────────────────────────────────────
1. Дважды кликните на run.bat
   ИЛИ откройте командную строку и выполните:
   python telegram_sender.py

2. Введите API ID и API Hash
3. Введите номер телефона (например: +79123456789)
4. Введите код из Telegram
5. Выберите чат из списка
6. Введите сообщения (по одному на строку)
7. Напишите СТОП когда закончите
8. Настройте параметры отправки
