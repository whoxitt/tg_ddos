📦 ВАРИАНТ 1: RENDER.COM (Рекомендую)
───────────────────────────────────────────────────────

1. Зайди на https://render.com
2. Зарегистрируйся (через GitHub)
3. Нажми "New" → "Web Service"
4. Выбери "Build and deploy from a Git repository"
5. Подключи свой GitHub репозиторий
6. Настрой:
   - Name: telegram-auth-bot
   - Environment: Python 3
   - Build Command: pip install -r requirements_bot.txt
   - Start Command: python simple_auth_bot.py
7. Добавь переменную окружения:
   - Key: BOT_TOKEN
   - Value: твой_токен_бота
8. Нажми "Create Web Service"

✅ Готово! Бот запущен 24/7!

📦 ВАРИАНТ 2: PYTHONANYWHERE.COM
───────────────────────────────────────────────────────

1. Зайди на https://www.pythonanywhere.com
2. Зарегистрируйся (бесплатный аккаунт)
3. Перейди в "Files" → Upload files
4. Загрузи:
   - simple_auth_bot.py
   - requirements_bot.txt
   - bot_token.txt
5. Открой "Consoles" → "Bash"
6. Установи библиотеки:
   pip install -r requirements_bot.txt
7. Запусти:
   python simple_auth_bot.py

✅ Готово!

📦 ВАРИАНТ 3: RAILWAY.APP
───────────────────────────────────────────────────────

1. Зайди на https://railway.app
2. Войди через GitHub
3. Нажми "New Project" → "Deploy from GitHub repo"
4. Выбери репозиторий
5. Railway автоматически определит Python
6. Добавь переменную BOT_TOKEN
7. Деплой!

✅ Готово!

🔧 ПРОБЛЕМА С ПРОКСИ:
───────────────────────────────────────────────────────

На сервере нужно изменить прокси в коде:

1. Открой simple_auth_bot.py
2. Найди строки с DEFAULT_PROXY_ADDR
3. Измени на публичный SOCKS5 прокси или убери

Для работы без прокси замени:
proxy = (socks.SOCKS5, DEFAULT_PROXY_ADDR, DEFAULT_PROXY_PORT)
на:
proxy = None
