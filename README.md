# Telegram Auto Message Sender

Программа для автоматической отправки сообщений в Telegram от вашего аккаунта.

## Возможности

✅ Отправка сообщений от вашего имени (не бот, а ваш аккаунт)
✅ Интервал между сообщениями (рекомендуется 10 секунд)
✅ Три режима работы:
   - По времени (например, 2 часа)
   - По количеству сообщений (например, 200 сообщений)
   - Отправить все введенные сообщения
✅ Ввод любого количества сообщений
✅ Автоматическая циклическая отправка (если сообщений меньше чем лимит)
✅ Статистика в реальном времени

## Установка

### 1. Установите Python
Убедитесь что у вас установлен Python 3.7 или новее.

### 2. Установите зависимости

```cmd
pip install -r requirements.txt
```

Или напрямую:

```cmd
pip install telethon
```

### 3. Получите API credentials

1. Перейдите на https://my.telegram.org
2. Войдите в свой аккаунт
3. Перейдите в "API development tools"
4. Создайте приложение (можно назвать как угодно)
5. Получите **api_id** и **api_hash**

## Запуск

```cmd
python telegram_sender.py
```

## Как использовать

### Шаг 1: Ввод API данных
Программа попросит:
- API ID
- API Hash
- Ваш номер телефона (с кодом страны, например: +79123456789)

При первом запуске вам придет код подтверждения в Telegram - введите его.

### Шаг 2: Выбор чата
Программа покажет список ваших чатов. Выберите нужный по номеру.

### Шаг 3: Ввод сообщений
Введите сообщения, каждое на новой строке.
Когда закончите - напишите **СТОП**

Пример:
```
Сообщение 1: Привет, как дела?
Сообщение 2: Что нового?
Сообщение 3: Как погода?
Сообщение 4: СТОП
```

### Шаг 4: Настройка отправки
Выберите:
- **Интервал** между сообщениями (в секундах, например 10)
- **Режим работы**:
  - **1** - По времени (например, 2 часа)
  - **2** - По количеству сообщений (например, 350)
  - **3** - Отправить все сообщения один раз

### Шаг 5: Подтверждение
Программа покажет настройки и попросит подтвердить запуск.

## Примеры использования

### Пример 1: Отправить 350 вопросов с интервалом 10 секунд
```
Интервал: 10
Режим: 2 (по количеству)
Количество: 350
```

### Пример 2: Работать 2 часа, отправляя сообщения каждые 10 секунд
```
Интервал: 10
Режим: 1 (по времени)
Часов: 2
```

### Пример 3: Отправить все введенные сообщения один раз
```
Интервал: 10
Режим: 3 (все сообщения)
```

## Циклическая отправка

Если вы ввели 50 сообщений, но хотите отправить 350:
- Программа будет отправлять сообщения по кругу
- После 50-го сообщения начнет с 1-го
- Продолжит пока не отправит 350 сообщений

## Остановка программы

Нажмите **Ctrl+C** в консоли для немедленной остановки.

## Важные замечания

⚠️ **Антиспам**
- Telegram может ограничить аккаунт при слишком частой отправке
- Рекомендуется интервал не менее 10 секунд
- Не злоупотребляйте отправкой в группах

⚠️ **Безопасность**
- Никому не передавайте api_id и api_hash
- Файл session_* содержит вашу сессию - храните в секрете
- Используйте только в личных целях

⚠️ **Лимиты Telegram**
- Группы могут иметь настройку "медленный режим" (slow mode)
- Программа не обходит эти лимиты, она просто отправляет с заданным интервалом

## Устранение проблем

### Ошибка: "Could not find the input entity"
- Убедитесь что вы являетесь участником выбранного чата
- Попробуйте сначала отправить сообщение вручную в этот чат

### Ошибка: "A wait of X seconds is required"
- Telegram ограничивает вас за спам
- Увеличьте интервал между сообщениями
- Подождите и попробуйте позже

### Ошибка: "Phone number banned"
- Ваш номер заблокирован в Telegram
- Используйте другой аккаунт
